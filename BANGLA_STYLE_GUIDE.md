# Bangla Style Guide

## Voice

Use warm, clear, customer-friendly Bangla. The audience includes homeowners, factory managers, farmers, and procurement teams. Prefer direct language over formal government phrasing.

Good: `আপনার বিদ্যুৎ বিল কমাতে আমরা সঠিক সোলার সিস্টেম বেছে দিতে সাহায্য করি।`

Avoid: `উক্ত কার্যক্রমের মাধ্যমে আপনার বিদ্যুৎ ব্যয়ের পরিমাণ হ্রাস করা সম্ভবপর হইবে।`

## Writing Rules

- Use standard Bangla spelling and punctuation.
- Use familiar customer terms such as `কোটেশন`, `সার্ভে`, `সাপোর্ট`, and `নেট মিটারিং` where they are clearer than forced translations.
- Keep brand names, model numbers, certifications, and utility names such as DESCO, DPDC, BREB, SREDA, and IEB in their recognized forms.
- Keep phone numbers, URLs, email addresses, watts, kilowatts, percentages, and warranty years accurate.
- Use Bangla numerals only when the surrounding copy is already using them consistently.
- Avoid excessive English transliteration when a common Bangla word is available.
- Keep calls to action conversational and specific.

## Technical Terms

Keep these terms stable across pages:

| English | Preferred Bangla |
| --- | --- |
| Solar panel | সোলার প্যানেল |
| Hybrid inverter | হাইব্রিড ইনভার্টার |
| Battery backup | ব্যাটারি ব্যাকআপ |
| Net metering | নেট মিটারিং |
| Site survey | সাইট সার্ভে |
| Quotation | কোটেশন |
| Maintenance | রক্ষণাবেক্ষণ |
| Load shedding | লোডশেডিং |

## QA Before Publishing

- Read the full sentence aloud for natural flow.
- Check that the copy does not promise guaranteed savings without qualification.
- Test the string at 320px and 375px viewport widths.
- Check labels, validation, success, and error messages together as one workflow.
- Ask a native Bangladesh speaker to review customer-facing campaign copy before release.
